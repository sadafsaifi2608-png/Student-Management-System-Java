#  Student Management System (Java)

A robust Command-Line Interface (CLI) application built with Java that demonstrates core Object-Oriented Programming (OOP) principles. This system allows for efficient management of student records, including adding, searching, and displaying data.

 ##  Features
- Add Student Records: Capture and store student details (Name, ID, Grade).
- Search Functionality:  Quickly locate specific student data using unique identifiers.
- Data Display: View a formatted list of all registered students.
- Input Validation: Ensures data integrity by handling user input errors.

 ##  Tech Stack & Concepts
- Language: Java
- Concepts Used: - Object-Oriented Programming (Classes, Objects, Encapsulation)
  - Java Collections (ArrayList/List)
  - Exception Handling
  - Scanner Class for User Input

## How to run
1. Clone the repository:
  git clone (https://github.com/sadafsaifi2608-png/Student-Management-System-Java.git)
2. Compile the Code:
   javac StudentManagementSystem.java
3. Run the application:
   java StudentManagementSystem
