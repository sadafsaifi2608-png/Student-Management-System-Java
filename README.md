# Student Management System (Java)

## Description
A menu-driven Java console application that manages student records.
It supports adding, viewing, updating, and deleting students using
Object-Oriented Programming concepts.

## Features
- Add Student
- View All Students
- Update Student
- Delete Student
- Menu-driven interface

## Technologies Used
- Java
- OOP
- ArrayList
- Scanner

## How to Run
1. Compile:
   javac StudentManagementSystem.java
2. Run:
   java StudentManagementSystem
